## OptiCore Demo Script (Panel Flow)

### Setup (2 minutes)
- **Log in as Chairman Admin** (chair scope with a valid `collegeId` + `chairmanProgramId`).
- In the header, **pick the Academic Period** (semester/year) you will demo.
- Open `Chairman → Evaluator` and confirm the grid loads.

### 1) Schedule plotting + conflict detection (5 minutes)
- In `EvaluatorTimetablingPanel`:
  - Select **Section**, **Subject**, **Instructor**, **Room**, **Day**, **Start time**.
  - Intentionally pick a slot that **conflicts** (same room/time or same instructor/time).
- Point out:
  - **Real-time conflict banner** (faculty/room/section overlap).
  - **Alternative Solutions** auto-suggests viable placements (DB-backed rooms + instructors).
- Click one **suggestion** to apply it (updates the plot controls).
- Re-run: the conflict list should clear.

### 2) Save to database + INS parity (4 minutes)
- Click **Add schedule** then **Save to database**.
- Open **INS Form 5B (Section)** or **INS Form 5C (Room)** for the same term:
  - Confirm the newly saved class appears immediately.
- (Optional) Show **Policy Justification** prompt by exceeding a load threshold, then save with a justification.

### 3) Central Hub Evaluator alignment (4 minutes)
- As **College Admin**, open `Admin → College → Central Hub Evaluator`.
- Confirm:
  - The same `ScheduleEntry` rows saved by the Chairman appear.
  - Conflict scan highlights any problematic rows and shows suggestion previews.

### 4) Schedule change request workflow + realtime notification (5 minutes)
- As **Instructor**, open `Faculty → My schedule`.
- Submit a **Schedule Change Request** for a class.
- As **College Admin**, open `Admin → College → Schedule change requests`:
  - Approve or reject; optionally run conflict checks in the review flow.
- Back as **Instructor**, show the **notification bell** updates with the status.

### 5) Admin dashboard analytics (3 minutes)
- As **College Admin** (or **DOI Admin**):
  - Open the dashboard and show charts are **live** (computed from `ScheduleEntry` + catalog scope).
  - Highlight **Room utilization** and **Faculty load distribution**.

### 6) Campus navigation (3 minutes)
- Open `Campus navigation`.
- Pick **Start** and **Destination room**.
- Click **Route / Navigate**:
  - Show the path generated by A* and the step-by-step guidance.

### Close (30 seconds)
- Summarize value: **conflict-free scheduling**, **accountable workflows**, **live visibility**, and **navigation integration** for students and staff.
